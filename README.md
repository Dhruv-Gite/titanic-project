# Titanic Survival Explorer

A Streamlit dashboard for exploring the Titanic passenger dataset, comparing
the saved survival classifiers, and trying predictions for passenger details.

## Run locally

Install the dependencies and start the app from this folder:

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

The app loads `Titanic-Dataset.csv` and the saved classifier files from the
project folder.
